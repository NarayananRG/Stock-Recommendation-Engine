# Frozen prospective model bundle

`frozen_2026` contains exactly seven models reconstructed from the frozen 2026 Stage 4A / 4A.1 fold. Training labels were available strictly before 2026-01-01. The bundle stays fixed for all of Stage 4A.3; refitting and prospective-outcome training are prohibited. The manifest binds model, feature, preprocessing, training-ID, reference-prediction, and serialized-file hashes.
