# Upload notes

This repository contains the complete generated Stage 2.2 and Stage 2.2.1 deliverables.

Two candidate-signal CSV files exceeded GitHub's 25 MiB web-upload limit and are stored as lossless gzip files:

- `stage2_2_1/results/stage2_2_1_candidate_signal_log.csv.gz`
- `stage2_2_results/stage2_2_candidate_signal_log.csv.gz`

Decompressing either `.csv.gz` file reproduces the original CSV byte-for-byte. Transient Python `__pycache__` files are intentionally excluded.
