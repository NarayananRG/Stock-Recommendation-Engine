# NextGen First Controlled Synthetic Challenger Experiment Report

## 1. Executive summary

The first controlled Simple Challenger experiment completed using synthetic data only.  The pipeline exercised deterministic/reference, logistic regression, random forest, and gradient boosting adapters across six preregistered scenarios and five preregistered seeds.  Classification: `SYNTHETIC_PIPELINE_VALIDATED_WITH_LIMITATIONS`.

## 2. Experiment purpose

This experiment validates the synthetic research pipeline mechanics: synthetic generation, PIT-safe features, chronological splitting, deterministic model fitting, predictions, cross-sectional ranking, synthetic economic evaluation, baseline-relative comparison, stability analysis, and immutable-style evidence.

## 3. Explicit synthetic-only statement

All training and evaluation rows were generated by `DETERMINISTIC_SYNTHETIC_V1`.  No NSE/NIFTY/Stage 4A.3/Stage 5D/Stage 6/live/MCP/official-market data was used for model training.

## 6. Scenario definitions

- `NULL_NO_SIGNAL`: Features contain no true predictive relation to future synthetic outcomes.
- `SIMPLE_LINEAR_SIGNAL`: Technical and momentum features carry a controlled linear signal.
- `NONLINEAR_SIGNAL`: Synthetic outcome depends on feature interactions and nonlinear thresholds.
- `REGIME_SHIFT`: The sign and strength of the feature/outcome relation changes over time.
- `NOISY_WEAK_SIGNAL`: A weak signal is present but dominated by synthetic noise.
- `ADVERSARIAL_DECEPTIVE`: Development-period correlation does not persist in final evaluation.

## 7. Dataset sizes

Each scenario/seed generated compact synthetic panels.  Sample row counts: ADVERSARIAL_DECEPTIVE/11: 2700, ADVERSARIAL_DECEPTIVE/29: 2700, ADVERSARIAL_DECEPTIVE/47: 2700, ADVERSARIAL_DECEPTIVE/83: 2700, ADVERSARIAL_DECEPTIVE/101: 2700, NOISY_WEAK_SIGNAL/11: 2700 ...

## 8. Temporal partitions

The experiment used strict chronological TRAIN, VALIDATION, and FINAL TEST boundaries with a five-session embargo.  No shuffled/random split was used and fold disjointness was enforced.

## 9. Model configurations

The only model families were deterministic/reference baseline, logistic regression, random forest, and gradient boosting.  Configurations were predefined; no hyperparameter search or final-test tuning was performed.

## 10. Seed set

Predeclared seeds: `[11, 29, 47, 83, 101]`.

## 11. Ranking methodology

Models were evaluated as cross-sectional rankers using deterministic score-descending ranking with `security_id` tie-breaks.  Top-K settings: `[5, 10, 20, 0.1]`.

## 12. Predictive metrics

Metrics include ROC-AUC, PR-AUC, Brier score, Brier baseline, Brier skill, IC, Rank IC, and Precision@K where mathematically defined.

## 13. Economic synthetic metrics

Synthetic-only Top-K average forward return, benchmark-relative Top-K return, and hit-rate style metrics were computed.  These are synthetic research metrics only and are not expected market return, real alpha, or live profitability.

## 14. Baseline-relative results

Each challenger was compared on identical observations, temporal boundaries, labels, benchmarks, cost assumptions, and missing-data rules.  The population-equality guard remained active.
