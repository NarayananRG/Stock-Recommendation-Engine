# Stage 4A.2 — Preregistered Economic Utility Validation

This stage tests whether already-frozen Stage 4A/4A.1 signal-time rankings improve the economics of selecting executable `BASELINE_PRIMARY` opportunities under the exact frozen Stage 2B.1 D1 and D0 engines.

No model is trained, calibrated, tuned, or selected here. Daily capacities are fixed at K=1 and K=2. Random controls use exactly seeds 0–499 per K, and paired moving-block bootstrap uses 2,000 replicates with seed 42 and block lengths 63, 21, and 126 sessions.

This experiment was designed after Stage 4A and Stage 4A.1 results were observed. It is a pre-registered follow-up robustness/economic-utility study, not a new untouched historical holdout.

Prospective paper trading is still required later. This stage is historical pseudo-OOS research only and does not implement Stage 5 or generate live recommendations.
